# 90 周复盘（每周一次，保持可持续）

## 1. 账号与安全

- [ ] **登录与权限**：管理员是否齐全；是否有异常登录提示
- [ ] **资料一致性**：头像/昵称/简介是否与当前版本一致
- [ ] **风险点**：是否出现平台警告、限流提示、违规提醒（记录原文）

## 2. 内容与素材

- [ ] **素材库更新**：本周新增案例是否按命名规范归档
- [ ] **内容产出**：各平台是否达到本周计划（数量写在你自己的周计划里，不写死在此）
- [ ] **高表现内容**：记录本周咨询最多的内容（标题/主题/触达路径）

## 3. 线索与转化

- [ ] **线索台账完整**：是否有“未记录的咨询”
- [ ] **漏斗复盘**：咨询 → 已回复 → 已预约 → 已到店 → 已成交（按平台统计）
- [ ] **原因归类**：未到店/未成交原因（价格/时间/信任/距离/需求不匹配等）

## 4. 口碑与评价

- [ ] **评价新增**：本周新增评价数量（写入你的周记录）
- [ ] **差评处理**：是否按流程处理并形成改进项
- [ ] **回复质量**：公开回复是否简洁、专业、无争辩
