# 平台清单：抖音（企业号 + 来客/本地生活）

目标：门店可被搜到；可咨询；可预约/下单；可核销/履约；可评价；可复盘线索来源。

## 0. 前置确认（必做）

- [ ] **主体与账号归属确认**（产出物：账号台账条目）
  - 使用企业主体或个体主体（与营业执照一致）
  - 管理员账号与手机号/邮箱已绑定
- [ ] **素材与话术已就绪**（引用：`10_素材与资料.md`）

## 1. 企业认证/蓝 V（必做）

- [ ] **进入认证入口**（动作：在抖音“企业服务/认证”入口发起）
  - 准备材料：营业执照、法人证件（按页面要求）、门店相关图片（如要求）
  - 验收：认证状态为“通过”；资料页可查看主体信息
- [ ] **认证信息一致性检查**（验收）
  - 店名/主体信息与营业执照一致
  - 如执照地址与实际经营地址不一致：准备统一解释口径（见 `10_素材与资料.md`）

## 2. 来客门店（POI）认领/新增（必做）

- [ ] **搜索门店 POI**
  - 动作：在“来客/门店管理”入口搜索门店名称
  - 结果分支：
    - 找到：进入“认领/管理”
    - 未找到：走“新增门店/创建门店”
- [ ] **提交门店基础信息**
  - 必填：门店名称、类目、联系电话、营业时间、地址/定位（按平台规则）
  - 图片：门头、环境、可证明经营的照片
  - 验收：门店状态为“可展示/可管理”
- [ ] **门店定位与资质地址策略（必做）**
  - 动作：把“展示地址/定位/资质地址”按同一策略填写并记录（避免前后矛盾）
  - 验收：审核不因地址/定位冲突反复驳回

## 3. 收款与结算（必做）

- [ ] **绑定收款账户**
  - 动作：在来客/结算相关入口绑定银行卡（对公/对私按主体要求）
  - 验收：状态显示“已绑定/可结算”
- [ ] **退款链路确认**
  - 动作：查看退款规则配置入口（如有）并确认可处理
  - 验收：明确“谁可发起退款、在哪处理、需要哪些证据”

## 4. 团购/到店服务商品（强建议，线下店优先）

- [ ] **套餐策略确定**（引用：`config.md` 的 `PACKAGE_STRATEGY`）
  - 引流款：降低首次体验门槛
  - 主推款：你的主力成交项目
  - 组合款：提升客单价的合理组合
- [ ] **创建团购/服务商品**
  - 动作：在来客“商品/团购管理”创建
  - 必填：名称、包含内容、适用范围、使用规则、有效期口径、预约方式、退款边界
  - 图片：门店/案例/项目图（真实）
  - 验收：商品状态为“可售”
- [ ] **核销闭环自测（必做）**
  - 动作：模拟一次“下单 → 到店 → 核销 → 结算”
  - 验收：核销成功；结算状态可追踪；出现异常可定位原因

## 5. 主页装修与转化组件（必做）

- [ ] **头像/昵称/简介/背景图设置**
  - 验收：与其他平台一致；简介不含违规留资
- [ ] **电话/咨询入口配置**
  - 动作：开通可用的咨询入口（电话、私信、预约等，按平台支持）
  - 验收：用户能在主页完成一次咨询动作
- [ ] **私信自动回复 + 关键词快捷回复**
  - 覆盖：报价前信息采集、预约、地址、质保、售后
  - 验收：抽测关键词触发正常；内容合规

## 6. 内容最小组合（必做）

- [ ] **置顶内容完成**
  - 置顶方向：门店可信（环境/工位）、案例对比、套餐解释与预约方式
  - 验收：用户第一次进主页能看懂你做什么、怎么预约
- [ ] **内容发布数量达标**（数量见 `VIDEO_MIN_PER_PLATFORM`）
  - 验收：每条内容都能指向“下一步动作”（私信/预约/团购）

## 7. 合规自检（必做）

- [ ] **禁词与承诺边界检查**（引用：`config.md` 的 `CLAIM_BOUNDARY`）
- [ ] **留资策略检查**（引用：`config.md` 的 `LEAD_CAPTURE_POLICY`）
- [ ] **图片/文案一致性**：门店名、地址口径一致，无夸大对比
