# 平台清单：闲鱼（同城服务/低成本测试渠道）

目标：账号可信；同城服务可被搜到；咨询可转化到预约；纠纷风险可控。

## 0. 前置确认（必做）

- [ ] **素材与话术就绪**（引用：`10_素材与资料.md`）
- [ ] **线索台账可用**（引用：`templates/线索台账.md`）

## 1. 账号基础（必做）

- [ ] **账号资料完善**
  - 头像/昵称/简介统一
  - 简介说明：主营 + 同城到店/预约方式（平台内）
  - 验收：资料无违规留资与夸大承诺
- [ ] **收款与实名能力确认**
  - 动作：按平台要求完成必要的实名认证/收款设置
  - 验收：收款能力可用；账户状态正常

## 2. 发布条目（必做）

- [ ] **发布“同城服务型条目”**
  - 标题：包含城市/贴膜/车衣等核心关键词（按平台规则）
  - 主图：门店/施工/案例（真实）
  - 详情：适用范围、施工时长口径、预约规则、质保边界、售后处理方式
  - 验收：条目可见；信息完整；咨询入口可用
- [ ] **发布“引流条目”（如你确实有可交付的实物/耗材）**
  - 验收：发货/到店履约方式写清，避免纠纷

## 3. 自动回复与议价策略（建议）

- [ ] **自动回复/快捷话术**
  - 覆盖：车型采集、方案建议、预约、地址、质保、售后
- [ ] **议价边界**
  - 动作：确定哪些条目可议价、议价范围口径（不写死金额）
  - 验收：不因随意议价导致低价纠纷

## 4. 信任增强（建议）

- [ ] **门店可信素材补充**
  - 门头、工位、施工过程、案例前后对比
  - 验收：用户看图能判断“真实门店经营”

## 5. 合规与风险（必做）

- [ ] **留资策略**：执行 `LEAD_CAPTURE_POLICY`
- [ ] **承诺边界**：执行 `CLAIM_BOUNDARY`
- [ ] **交易说明清晰**：服务内容、适用范围、退款边界写清
