# 平台清单：大众点评（门店认领 + 团购 + 口碑）

目标：门店信息可被搜到且可控；团购/预约可用；相册与案例完善；评价稳定增长并可处理差评。

## 0. 前置确认（必做）

- [ ] **门店基础信息定稿**（引用：`templates/门店信息表.md`）
- [ ] **门头/环境/案例素材就绪**（引用：`10_素材与资料.md`）

## 1. 门店搜索与认领/新增（必做）

- [ ] **搜索门店**
  - 动作：在大众点评“商家/认领/入驻”入口搜索门店名称与地址关键词
  - 结果分支：
    - 找到：申请认领
    - 未找到：新增门店信息
- [ ] **提交资质认证**
  - 常见材料：营业执照、法人信息、门头照、店内环境照（按页面要求）
  - 验收：认证通过；获得可编辑商家信息权限
- [ ] **信息一致性检查（必做）**
  - 动作：检查门店名、电话、类目、地址口径是否一致
  - 如执照地址与实际经营地址不一致：统一口径并记录，避免反复驳回

## 2. 商家信息完善（必做）

- [ ] **基础信息**
  - 营业时间、联系电话、门店地址、导航定位
  - 验收：用户导航可用；电话可接通
- [ ] **类目选择精准**
  - 动作：选择与你主营最贴合的类目（贴膜/美容/养护等按实际）
  - 验收：搜索相关关键词能出现更匹配的类目入口
- [ ] **相册上传**
  - 必含：门头、环境、工位、施工过程、案例前后对比、资质（如适用）
  - 验收：相册能支撑“真实经营 + 专业可信”
- [ ] **商家公告/服务须知**
  - 必含：预约规则、施工时长口径、质保与售后边界、停车/到店提示（如有）
  - 验收：无夸大承诺；无违规留资

## 3. 团购/套餐（强建议，线下优先）

- [ ] **套餐策略确定**（引用：`config.md` 的 `PACKAGE_STRATEGY`）
- [ ] **创建团购套餐**
  - 必填：包含内容、适用车型/范围、使用规则、预约方式、退款边界、有效期口径
  - 图片：真实门店/案例/项目图
  - 验收：团购可购买；使用规则清晰无歧义
- [ ] **预约能力（如平台支持）**
  - 动作：配置可预约时段与规则（取消/改期口径）
  - 验收：用户可完成一次预约；你能收到通知并能处理

## 4. 在线咨询与回复（必做）

- [ ] **开启在线咨询入口**
  - 验收：用户可发起咨询；你能收到并回复
- [ ] **自动回复与快捷回复**
  - 覆盖：车型采集、项目推荐、预约、地址、质保、售后
  - 验收：回复内容合规、可执行

## 5. 评价与口碑 SOP（必做）

- [ ] **评价引导路径梳理**
  - 动作：明确“用户从哪里进入评价页”；将话术写入 `20_线索与跟进SOP.md`
  - 验收：到店后能稳定引导用户完成评价
- [ ] **差评处理流程落地**
  - 动作：公开回复模板 + 私下沟通模板 + 记录归因
  - 验收：差评处理有记录；形成可执行改进项

## 6. 上线自检（必做）

- [ ] **可搜到**：用不同关键词搜索（店名/贴膜/车衣等）能找到门店
- [ ] **可导航**：从门店页一键导航可用
- [ ] **可咨询**：在线咨询可用
- [ ] **可购买/预约**：团购或预约链路可用
