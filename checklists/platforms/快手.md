# 平台清单：快手（企业号 + 小店/本地能力）

目标：账号可信；可咨询；商品/服务可下单；履约与售后可处理；线索可追踪。

## 0. 前置确认（必做）

- [ ] **素材与话术就绪**（引用：`10_素材与资料.md`）
- [ ] **线索台账可用**（引用：`templates/线索台账.md`）

## 1. 企业号认证（必做）

- [ ] **进入企业认证入口并提交资料**
  - 常见材料：营业执照、法人证件（按页面要求）
  - 验收：认证通过；账号资料页可查看主体信息
- [ ] **一致性检查**
  - 店名/主体/类目与实际一致；地址口径统一

## 2. 主页装修与基础信息（必做）

- [ ] **头像/昵称/简介/背景图**
  - 验收：与其他平台一致；简介不含违规留资
- [ ] **消息提醒开启**
  - 动作：开启私信/订单/系统通知提醒
  - 验收：你能及时收到咨询与订单通知

## 3. 小店/服务能力开通（必做）

- [ ] **开通快手小店（或平台对应商家能力）**
  - 动作：按官方入口完成开通流程
  - 验收：后台可见“商品/订单/售后”等基础模块
- [ ] **绑定收款账户**
  - 验收：显示已绑定；结算信息可查看

## 4. 商品/服务上架（必做）

- [ ] **建立商品/服务结构**
  - 动作：按你的主营分类（贴膜/车衣/改色等）建立分类
  - 验收：用户能快速找到目标项目
- [ ] **上架数量达标**（如做实物，数量见 `SKU_MIN_DY_KS`）
  - 每个条目必含：标题、主图、详情、适用范围、预约/发货、售后边界
  - 验收：条目可售；关键信息不缺失
- [ ] **运费模板/发货时效（如适用）**
  - 验收：运费口径清晰；发货/到店履约规则清晰

## 5. 私信与客服（必做）

- [ ] **私信自动回复**
  - 覆盖：车型采集、方案建议、预约、地址、质保、售后
  - 验收：触发正常；内容合规
- [ ] **快捷短语**
  - 验收：常见问题可在短时间内回复并引导下一步

## 6. 内容最小组合（必做）

- [ ] **置顶内容**
  - 方向：门店可信、案例对比、套餐/服务解释
  - 验收：用户第一次进入即可理解你做什么、怎么预约
- [ ] **发布数量达标**（数量见 `VIDEO_MIN_PER_PLATFORM`）

## 7. 履约与售后（必做）

- [ ] **订单处理路径明确**
  - 动作：确认在哪里查看订单、如何联系客户、如何标记完成
  - 验收：模拟一次从下单到完成的处理流程
- [ ] **退款/售后处理路径明确**
  - 验收：知道入口与所需证据；能在台账中记录原因

## 8. 合规自检（必做）

- [ ] **留资策略**（`LEAD_CAPTURE_POLICY`）已执行
- [ ] **承诺边界**（`CLAIM_BOUNDARY`）已执行
