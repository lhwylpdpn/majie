# 平台清单模板（复制后新增平台用）

目标：一句话写清楚“这个平台最终要做到什么”。

## 0. 前置确认（必做）

- [ ] 素材与话术就绪（引用 `10_素材与资料.md`）
- [ ] 线索台账可用（引用 `templates/线索台账.md`）

## 1. 认证/入驻（必做）

- [ ] 提交主体资质并通过审核
- [ ] 信息一致性检查（店名/电话/类目/地址口径）

## 2. 店铺/门店信息（必做）

- [ ] 头像/昵称/简介/背景图完成
- [ ] 电话/私信/预约入口可用

## 3. 商品/团购/服务（按平台能力）

- [ ] 创建核心条目并上线
- [ ] 履约与售后规则明确

## 4. 内容与转化（必做）

- [ ] 置顶内容完成
- [ ] 发布数量达到 `VIDEO_MIN_PER_PLATFORM` 或平台对应指标
- [ ] 评论/私信话术可用且合规

## 5. 自测（必做）

- [ ] 可搜到
- [ ] 可咨询
- [ ] 可预约/下单
- [ ] 可履约/可退款（如适用）
