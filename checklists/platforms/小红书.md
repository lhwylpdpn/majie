# 平台清单：小红书（企业专业号 + 内容种草 + 私信转化）

目标：账号可信；内容矩阵可持续；私信转化可执行；线索可追踪；合规不踩线。

## 0. 前置确认（必做）

- [ ] **素材与案例库就绪**（引用：`10_素材与资料.md`）
- [ ] **线索台账可用**（引用：`templates/线索台账.md`）

## 1. 企业专业号（必做）

- [ ] **进入专业号/企业认证入口并提交资料**
  - 常见材料：营业执照、主体信息（按页面要求）
  - 验收：专业号状态正常；资料可编辑
- [ ] **账号安全**
  - 动作：绑定手机号/邮箱；开启必要的安全校验
  - 验收：管理员可稳定登录；异常可找回

## 2. 主页三件套（必做）

- [ ] **头像/昵称/简介**
  - 简介必含：主营、服务范围、预约方式（平台内私信/评论引导）
  - 验收：不出现违规留资；不夸大承诺
- [ ] **置顶内容规划**
  - 置顶方向：案例对比合集、门店与施工流程说明、预约规则与质保口径
  - 验收：新用户不用翻很久就能理解并发起咨询

## 3. 笔记矩阵（必做，数量见 `NOTE_MIN_XHS`）

- [ ] **内容分类确定（至少覆盖以下方向）**
  - 场景痛点：隔热/隐私/眩光/防刮等（按实际）
  - 案例对比：同角度前后对比 + 过程证据
  - 施工科普：为什么要这样施工、注意事项
  - 门店可信：环境/工位/师傅/流程
- [ ] **封面模板统一**
  - 验收：封面可读、干净；不堆砌卖点；不出现违规承诺
- [ ] **发布数量达标**
  - 验收：达到 `NOTE_MIN_XHS`；每篇都有“下一步动作”（私信/评论咨询/预约）
- [ ] **标签与话题**
  - 动作：每篇选择与内容强相关的话题标签
  - 验收：标签不过度泛化；不使用不相关热词

## 4. 评论区与私信转化（必做）

- [ ] **评论区答疑模板**
  - 覆盖：车型/预算采集、预约引导、质保口径
  - 验收：公开评论不留外部联系方式
- [ ] **私信自动回复（如可用）或快捷话术**
  - 覆盖：信息采集 → 给方案 → 给可选时间 → 引导到店
  - 验收：与 `20_线索与跟进SOP.md` 的报价逻辑一致
- [ ] **线索入台账**
  - 验收：每个有效私信线索都进入台账并标记来源笔记

## 5. 合规自检（必做）

- [ ] **留资策略**：执行 `LEAD_CAPTURE_POLICY`
- [ ] **承诺边界**：执行 `CLAIM_BOUNDARY`
- [ ] **图文真实性**：案例与施工图不盗用、不夸大对比
