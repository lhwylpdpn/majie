# 多平台门店获客与店铺搭建清单

目的：用同一套可勾选的清单，管理汽车贴膜店在多个平台的基础搭建、内容资产、线索跟进与口碑维护。

适用平台：抖音 / 大众点评 / 快手 / 小红书 / 闲鱼 / 淘宝（可扩展）

## 使用方式

- 第一次搭建：按 `checklists/00_总清单.md` 从上到下执行。
- 只做某个平台：直接打开 `checklists/platforms/<平台>.md` 执行“必做项”。
- 每周复盘：用 `checklists/90_周复盘.md` 做一次巡检（账号安全、评价、线索、素材更新）。
- 新增平台/门店：复制 `checklists/_模板_平台清单.md` 或 `checklists/_模板_门店.md` 修改即可。

## 目录说明

- `多平台商品上架字段总表_马洁填写版.xlsx`：**跨平台字段总表（给店主填）**。门店通用信息 / 套餐填写（80 字段×6 套餐）/ 平台必填对照 / 各平台后台字段明细 / 素材清单 / 合规话术 / 发布进度。配合 `checklists/30_多平台发布工具与字段口径.md` 看。
- `checklists/00_总清单.md`：跨平台总 checklist（建议以此为主）。
- `checklists/10_素材与资料.md`：素材、资质、话术、价格表、案例库的准备清单。
- `checklists/20_线索与跟进SOP.md`：线索字段、跟进节奏、评价引导与差评处理。
- `checklists/30_多平台发布工具与字段口径.md`：批量发布工具结论（没有通用工具）+ 各平台商品上架的差异与字段别称。
- `checklists/platforms/`：各平台清单（认证、门店/店铺、商品/团购、转化、履约、合规）。
- `checklists/templates/`：表格模板与命名规范（复制后按门店/月份维护）。

## 运行与测试命令

本仓库为文档型清单，无需运行命令。
