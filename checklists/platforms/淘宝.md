# 平台清单：淘宝（更偏实物交易；按你的业务决定投入）

目标：店铺可稳定运营；商品信息完整；客服/运费/售后链路可跑通；风险可控。

## 0. 前置确认（必做）

- [ ] **确认经营形态**
  - 如果主要做“到店贴膜服务”：优先做本地生活平台；淘宝仅做“材料/耗材/配件”等更匹配形态
  - 验收：明确淘宝上架的交付方式（发货/到店）
- [ ] **素材与话术就绪**（引用：`10_素材与资料.md`）

## 1. 开店与认证（必做）

- [ ] **选择店铺类型并完成认证**
  - 动作：按淘宝官方开店入口选择个人/企业主体并提交资料
  - 验收：店铺创建成功；可进入商家后台
- [ ] **绑定收款账户**
  - 动作：按后台指引绑定支付宝/对公或对私账户
  - 验收：支付与结算能力可用

## 2. 店铺基础设置（必做）

- [ ] **店铺信息**
  - 店铺名、头像、简介、主营类目
  - 验收：信息合规、可读；不含夸大承诺
- [ ] **基础装修（最小可用）**
  - 店招/首页模块/分类导航（按实际主营）
  - 验收：用户能快速找到核心商品
- [ ] **千牛客服可用**
  - 动作：登录千牛；设置欢迎语与快捷短语
  - 验收：能收到并回复一次咨询

## 3. 商品上架（必做，数量见 `SKU_MIN_TB`）

- [ ] **类目与属性填写正确**
  - 验收：不因类目错误导致流量或违规问题
- [ ] **标题/主图/详情页模板统一**
  - 详情页必含：规格/适配范围、交付方式、发货时效或预约规则、售后边界
  - 验收：信息完整、无夸大对比与绝对化承诺
- [ ] **上架数量达标**
  - 验收：达到 `SKU_MIN_TB`；每个商品可下单

## 4. 运费、发货与售后（必做）

- [ ] **运费模板**
  - 验收：地区/计费规则清晰；不与实际成本严重偏离
- [ ] **发货时效/预约规则**
  - 验收：用户下单前即可看懂履约方式
- [ ] **退款/售后规则**
  - 验收：能定位入口并处理；规则与对外口径一致

## 5. 上线自测（必做）

- [ ] **下单链路自测**：加入购物车/下单/支付（用最小成本方式模拟）
- [ ] **退款链路确认**：知道入口与处理材料
- [ ] **客服链路自测**：能收到并回复咨询

## 6. 合规自检（必做）

- [ ] **留资策略**：执行 `LEAD_CAPTURE_POLICY`
- [ ] **承诺边界**：执行 `CLAIM_BOUNDARY`
