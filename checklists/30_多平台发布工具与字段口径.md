# 多平台发布：有没有能批量上架的工具

结论先说：**没有**能一次把商品/团购批量上架到美团、点评、抖音、快手、小红书、闲鱼、淘宝的通用工具。
市面上说的"一键分发"工具，解决的是**发内容**（视频/图文），不是**建商品**。

配套交付物：`多平台商品上架字段总表_马洁填写版.xlsx`（与本文件同目录），字段口径全在里面。

---

## 一、工具分三类，各管一段

| 类型 | 代表 | 能做什么 | 不能做什么 |
|---|---|---|---|
| 内容分发工具 | 蚁小二、易媒助手、推兔、新榜小豆芽 | 一份图文/视频，一次发到 30-40+ 平台；定时、批量、多账号；发布时可挂 POI 位置、挂已上架的团购链接 | 不能建商品、不能建团购、不能改价；只挂已经存在的商品 |
| 平台自带批量能力 | 美团经营宝、抖音来客（连锁版）、快手本地生活、千牛 | 连锁/多店商家可批量建品、批量改价 | 单店基本是手工建；开放平台 API 要服务商或连锁资质才给 |
| 服务商 / 代运营 | 各平台本地生活服务商 | 有平台侧的建店建品权限，能代建、代运营 | 要抽佣或服务费，账号与数据不在自己手里 |

所以现实路径只有一条：
**在 Excel 里把字段一次备齐 → 每个平台照表录一次 → 后续改价改规则回 Excel 改。**
六个平台 × 3 个套餐 = 18 个商品条目，第一次手工录入每个平台约 2-3 小时，之后维护按条改，很轻。

## 二、什么值得花钱，什么不值得

- **值得**：内容分发工具（省的是"同一支视频发六个平台"的重复劳动，一个月几十块）。发视频时挂 POI 团购，是本地流量最便宜的入口。
- **不值得**：所谓"批量上架/批量铺货"工具。单店商品就那么几条，工具的钱不如拿去拍素材。
- **慎用**：要账号密码登录的第三方工具。优先用官方授权/扫码登录，密码直登有被判定异常登录的风险。

## 三、每个平台"商品"这件事的现实差异

| 平台 | 商品形态 | 上架方式 | 关键卡点 |
|---|---|---|---|
| 美团 / 大众点评 | 团购套餐 | 经营宝手工建（连锁可批量导入） | 名称由系统拼接，不能手改；品牌+质保+材质选错，名字就错 |
| 抖音来客 | 团购套餐 | 来客后台手工建 | 必须先把 POI 门店认领、绑收款账户，否则建不了品 |
| 快手本地生活 | 团购套餐 | 商家后台手工建 | 图片审核最严：禁黑边、禁截图、禁第三方水印 |
| 小红书 | 团购 + 笔记 | 专业号 → POI 认领 → 本地生活商品；笔记单独发 | 汽车服务类目能否自助开通需后台确认，可能要服务商报白 |
| 闲鱼 | 服务/闲置条目 | App"发服务"入口 | 标题前 15 字决定曝光；类别树随版本变 |
| 淘宝 | 服务类商品 或 实物膜 | 千牛发布 | 服务类目要执照经营范围含汽车美容；SKU 按车型分档最稳 |

## 四、字段口径的坑（各平台叫法不同，实际是同一件事）

| 同一件事 | 各平台叫法 |
|---|---|
| 顾客实际付多少 | 团购价 / 顾客实际支付 / 售价 / 一口价 |
| 原价 | 门市价 / 商品价格 / 原价 |
| 买完多久内能用 | 团购使用有效期 / 客户可消费日期 / 有效期 |
| 什么时候能用 | 不可用日期 / 每日消费时段 / 可用时段 |
| 几人/几车 | 建议用餐人数 / 建议人数（贴膜店填 1 车） |
| 在哪核销 | 适用门店 / 核销员 / 门店 POI |

同一字段换个名字就漏填，是审核被驳回最常见的原因之一——这张表的价值就在这。

## 五、字段资料的来源与可信度

- 美团 / 大众点评：**高**。来自经营宝后台逐字段记录（见 `platforms/美团_车衣团购字段.md`、`platforms/美团_改色膜团购字段.md`），可直接照填。
- 抖音来客、快手：**较高**。来自后台建品流程 + 官方商品发布规则。
- 小红书、闲鱼、淘宝：**中**。来自公开资料与流程整理，具体类目树和必填项会随版本变，上架时以系统标红为准。
- 不确定的字段在表里标了"待核实"，没有硬编。
